# ANARISE VPN — Бесплатный кроссплатформенный VPN (Android, Windows, macOS)

## VPN-клиент со встроенными публичными конфигурациями (NaiveProxy, Hysteria2, VLESS, Mieru)

**ANARISE VPN** — это лёгкий, быстрый и полностью бесплатный VPN-клиент с открытым исходным кодом для **Android**, **Windows** и **macOS**. Приложение разработано для надёжного обхода блокировок (DPI) и защиты приватности в сети с помощью передовых протоколов маскировки трафика.

## Клиент Android (/android)

Полноценный и быстрый **бесплатный vpn для андроид** с графическим интерфейсом. Это надёжный **naiveproxy android client**, **vless android клиент** и **mieru android client**, поддерживающий обход современных систем DPI.

### Основные фичи
*   **Поддержка NaiveProxy** — обход блокировок с маскировкой под стандартный трафик Chrome (HTTP/2).
*   **Hysteria2 & VLESS** — высокая скорость, низкая задержка и поддержка обфускации **Salamander**.
*   **Mieru** — обход блокировок по протоколу Mieru (TCP/UDP).
*   **Вкладка «Внешние»** — автоматическая загрузка, параллельная проверка пинга и фильтрация публичных серверов.
*   **Раздельное туннелирование (Split Tunneling)** — выбор приложений, работающих через VPN.
*   **Быстрый пинг** всей истории в один клик.

### Доверие к серверам

ANARISE — VPN-клиент, а не оператор серверов из внешних списков. Проверка доступности и прокси-трафика показывает, что сервер отвечает в момент проверки; она не подтверждает личность оператора и безопасность его инфраструктуры. Подключайтесь только к серверам, которым доверяете: оператор VPN-сервера может видеть исходящий IP и сетевые метаданные соединений.

### Сборка
Требуются Android SDK и Java 17. Для `assembleRelease` также нужны путь к keystore и параметры подписи (`ANARISE_STORE_FILE`, `ANARISE_STORE_PASSWORD`, `ANARISE_KEY_ALIAS`, `ANARISE_KEY_PASSWORD`); не храните ключ подписи в репозитории.
```bash
cd android
./gradlew assembleRelease
```
Скомпилированный APK появится по пути: `app/build/outputs/apk/release/app-release.apk`.

## Клиент Windows (/windows)

Легковесный десктопный **vpn клиент windows** на базе .NET 8 WPF, использующий WebView2 для отображения интерфейса.

### Основные фичи
*   **Системный прокси-режим** — автоматическое переключение пользовательских настроек прокси Windows (SOCKS5/HTTP на localhost). Текущая сборка приложения всё равно запрашивает права администратора при запуске, поскольку также поддерживает TUN-режим и управление firewall.
*   **Kill Switch** — блокировка исходящего трафика через Windows Firewall при непредвиденном разрыве туннеля с сохранением доступа к серверу и локальной сети.
*   **Автозагрузка ядер** — при первом запуске приложение само скачивает стабильные бинарные сборки `xray.exe`, `hysteria.exe` и `mieru.exe` с официальных релизов на GitHub с проверкой SHA-256.
*   **Интерактивный лог** — вывод логов работы ядер в реальном времени прямо на вкладке логов.
*   **Автозапуск** и сворачивание в системный трей.
*   **Внешние списки** с параллельной верификацией реального HTTPS-трафика и автоматической сортировкой.
*   **Server Explorer** — поиск серверов, фильтрация по регионам и отображение состояния защиты.

### Сборка
Требуется .NET 8.0 SDK.
```powershell
cd windows
dotnet publish -c Release -r win-x64 --self-contained false
```
Результат сборки будет находиться в папке `bin/Release/net8.0-windows/publish/`.

## Клиент macOS (/macos)

Легковесный десктопный **vpn клиент macos** на базе .NET 8, использующий нативный WebKit (WKWebView) для отображения идентичного интерфейса и системные утилиты macOS для управления сетью.

### Основные фичи
*   **Системный прокси macOS** — автоматическое переключение SOCKS5/HTTP прокси через системную утилиту `networksetup` с автоопределением активного сетевого интерфейса (Wi-Fi/Ethernet).
*   **TUN-режим (`utun85`) и Kill Switch через `pfctl`** — системное туннелирование всего трафика и надёжная защита от утечек данных при разрыве VPN-соединения с помощью пакетного фильтра macOS (`pfctl`).
*   **Автозагрузка ядер** — при первом запуске приложение автоматически скачивает `xray`, `hysteria`, `mieru` и `tun2socks` под архитектуру вашего Mac с проверкой SHA-256.
*   **Идентичный функционал и UI** — полная поддержка VLESS, VMess, NaiveProxy, Hysteria2 и Mieru, подписок, внешних каталогов, параллельного сканирования, замера скорости и шифрованного хранилища (`AES-GCM`).
*   **Кроссплатформенная архитектура** — автономные сборки (не требуют установки .NET) как для Apple Silicon (`arm64` — M1/M2/M3/M4), так и для Intel (`x64`).
*   **DMG-установщик** — готовый образ диска с ярлыком `/Applications` и скриптом быстрой установки.

### Установка и первый запуск на macOS
1. Скачайте подходящий образ `.dmg` на странице [Releases](https://github.com/pasnya/anarise-vpn/releases/latest):
   * **`AnariseVPN-macOS-arm64-...dmg`** — для компьютеров Mac на чипах **Apple Silicon (M1, M2, M3, M4)**.
   * **`AnariseVPN-macOS-x64-...dmg`** — для компьютеров Mac на процессорах **Intel (Core i5, i7, i9)**.
2. Откройте скачанный `.dmg` и перетащите **`Anarise.app`** в папку **`Applications`**.
3. **Обход предупреждения macOS Gatekeeper при первом запуске** (так как сборка распространяется бесплатно с открытым кодом без платной подписки Apple Developer ID, при первом открытии macOS может показать окно *«Файл „Anarise“ невозможно открыть, так как Apple не может проверить его на наличие вредоносного ПО»*). Разрешить запуск нужно **только один раз** любым из трёх способов:
   * **Способ 1 (мышкой в Finder, без Терминала):** Нажмите «ОК» в окне предупреждения → откройте папку **Программы (`Applications`)** → нажмите на **Anarise** **правой кнопкой мыши** (или удерживая `Control` + клик) → выберите **«Открыть»** → в появившемся окне подтвердите нажатием **«Открыть»**.
   * **Способ 2 (через Системные настройки):** Нажмите «ОК» → откройте **Системные настройки** → **Защита и безопасность (Конфиденциальность и безопасность)** → **Основные** → внизу окна нажмите кнопку **«Подтвердить вход» (Открыть в любом случае)** рядом с упоминанием `Anarise`.
   * **Способ 3 (одной командой в Терминале):** Откройте **Терминал** и выполните:
     ```bash
     xattr -cr /Applications/Anarise.app && open /Applications/Anarise.app
     ```
     *(Также внутри образа `.dmg` лежит готовый скрипт `Установить и Открыть Anarise.command`, который автоматически копирует приложение в `/Applications`, снимает карантин и запускает его).*

### Сборка
Требуется .NET 8.0 SDK.
```bash
cd macos
# Сборка для Apple Silicon (M1/M2/M3/M4):
./build-macos.sh osx-arm64

# Сборка для Intel Mac:
./build-macos.sh osx-x64
```
Результат сборки упаковывается в готовый бандл приложения `macos/Anarise.app` и образ установщика с ярлыком Applications: `macos/AnariseVPN-macOS-<arch>.dmg`.
