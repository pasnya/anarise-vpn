# Проверка внешних серверов

Каталог источников находится в `shared/external-sources.json` и включается в Windows publish и Android assets. Восемь списков принадлежат проектам 0xRadikal, barry-far, roosterkid, V2RayRoot и Epodonios. Поле `updateMinutes` описывает заявленный авторами интервал публикации; доступность и соблюдение интервала авторами не гарантируются.

Приложение загружает свежие данные при открытии вкладки и затем каждые 15 минут, пока вкладка открыта и VPN отключён. Кнопка обновления запускает проверку вручную. Для каждого источника предусмотрено зеркало jsDelivr, которое может отставать от GitHub. Ошибки источников записываются в лог. Размер каждого ответа ограничен 4 МиБ.

Поддерживаются VLESS, VMess, Naive HTTPS, Hysteria2 и Mieru. Неподдерживаемые протоколы не включаются. Источники чередуются, одинаковые ссылки с разными названиями удаляются.

## Условия доступности

1. TCP-подключение используется только для порядка проверки. Его неудача не исключает сервер. Hysteria2 использует UDP и не проходит этот TCP-фильтр.
2. Для кандидата запускается соответствующее VPN-ядро и ожидается готовность SOCKS-порта до 5 секунд.
3. Через SOCKS выполняются HTTPS-запросы к Google, Cloudflare и Mozilla с обычной проверкой сертификата. Перенаправления запрещены; проверяются ожидаемые код и тело ответа.
4. Успех у двух разных адресов означает «Трафик подтверждён». Дважды успешный запрос только к одному адресу означает «Частичная доступность». Задержка измеряется по этим запросам.
5. Если успешных кандидатов нет, проверка продолжает следующие чанки до конца списка. Windows запускает до трёх ядер одновременно, Android проверяет последовательно из-за общего SOCKS-порта SDK. Успешные результаты показываются сразу.

Отсутствующее ядро, ошибка его запуска, неверная конфигурация и занятый локальный порт имеют отдельные статусы. Проверка не запускается при активном VPN. Результаты старше 15 минут считаются устаревшими.

Проверка подтверждает HTTPS-трафик в текущей сети. Она не гарантирует доступность любых сайтов, скорость, долговременную стабильность, UDP или корректность системного TUN-маршрута.

## Локальные проверки

```powershell
dotnet run --project tests/LinkParserHarness -- --probe-tests
dotnet run --project tests/LinkParserHarness -- --external-scan-tests
cd android
.\gradlew.bat assembleDebug testDebugUnitTest
```

Живой диагностический прогон с корня проекта:

```powershell
dotnet run --project tests/LinkParserHarness -- --external-live-check
```

Он загружает актуальный каталог и проверяет первые 30 ссылок через ядра из `%LOCALAPPDATA%\AnariseVPN\binaries`. Вывод содержит только количества и статусы. Этот прогон следует запускать при отключённом VPN, чтобы его результат отражал доступность из исходной сети.
