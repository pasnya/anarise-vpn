# ANARISE VPN v1.4.24

## Исправлено

- Android: приложение v1.4.23 закрывалось сразу при запуске. Release-сборка с R8 (full mode) удаляла конструкторы регистраторов ML Kit, из-за чего сканер QR-кодов падал при открытии главного экрана. Добавлены правила R8, сохраняющие эти классы.

## Как обновиться на Android

Встроенное обновление в v1.4.23 недоступно, потому что приложение не запускается. Скачайте `AnariseVPN-Android-arm64-v1.4.24.apk` с этой страницы и установите поверх текущей версии — удалять приложение не нужно, настройки сохранятся.

## Артефакты

- `AnariseVPN-Windows-x64-v1.4.24.zip`
- `AnariseVPN-macOS-arm64-v1.4.24.dmg` и `.zip`
- `AnariseVPN-macOS-x64-v1.4.24.dmg` и `.zip`
- `AnariseVPN-Android-arm64-v1.4.24.apk`

Изменений для Windows и macOS нет — версия поднята для единообразия релиза.
