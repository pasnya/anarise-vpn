# ANARISE VPN v1.4.16

## Что нового

- **Windows Kill Switch через Windows Firewall:** реализована надёжная блокировка исходящего интернет-трафика (`Anarise VPN - Kill Switch Block`) при неожиданном завершении ядра или обрыве туннеля, с сохранением доступа к IP активного VPN-сервера и локальной сети. Автоматическое снятие блокировки при штатном отключении, переподключении и аварийном восстановлении сессии.
- **Корректное определение Exit IP:** опрос внешнего IP переведён на локальный SOCKS5-прокси активного ядра (`socks5://127.0.0.1:{socksPort}`) с HTTPS-эндпоинтом `ipwho.is` (и резервным `ip-api.com`), что обеспечивает работу для всех протоколов и кастомных портов, включая Mieru.
- **Замер скорости в режиме системного прокси:** добавлен расчёт дельты сетевого трафика активного физического адаптера при выключенном TUN-драйвере (вместо постоянного нулевого значения).
- **Синхронизация протоколов и транспорта:** добавлена полная поддержка транспорта `httpupgrade` в LinkParser на обеих платформах, исправлена передача `serviceName` для VMess gRPC, а также проброс `alpn` и `fingerprint` в TLS-конфигурациях на Android.
- **Поддержка VMess в Android:** добавлены парсинг и валидация ссылок `vmess://` из буфера обмена, сканирование QR-кодов, декодирование параметров и имени сервера из Base64 JSON, дедупликация в истории.
- **Остановка внешнего сканирования:** добавлена возможность прерывания запущенного процесса проверки внешних конфигураций («Стоп») на Windows и Android.
- **Управление сетевыми событиями на Android:** слушатели статуса в `VyomVpnManager` переведены на потокобезопасный `CopyOnWriteArraySet`, устраняя конфликт между Quick Settings Tile и ViewModel. Исправлен перезапуск Mieru и Hysteria2 при восстановлении сети в `networkCallback`.
- **Чистота сборки и диагностика:** полностью устранены предупреждения компилятора C# в проекте Windows (0 предупреждений, 0 ошибок) и предупреждения Kotlin в Android SDK; расширен набор автоматических тестов в CI/CD.

## Артефакты

- `AnariseVPN-Windows-x64-v1.4.16.zip` — Windows x64, framework-dependent publish; требуются .NET 8 Desktop Runtime и WebView2 Runtime.
- `AnariseVPN-Android-debug-v1.4.16.apk` — ARM64 debug APK для тестирования; не production-подпись и не предназначен для обновления production-версии.
- `SHA256SUMS.txt` — контрольные суммы приложенных файлов.

Production APK будет собран CI отдельно после настройки GitHub Secrets с действующим Android keystore. Не заменяйте им debug APK до проверки подписи и установки.
