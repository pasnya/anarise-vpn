# ANARISE VPN v1.4.16

## Что нового

- Внешние списки проверяются до первого успешного чанка или исчерпания списка. Неудачный TCP-ping не исключает конфигурацию; Hysteria2 проверяется через собственное QUIC-ядро, Mieru — через Mieru.
- Доступность и задержка подтверждаются HTTPS-трафиком через выбранное ядро. Проверяются точные ответы Google, Cloudflare и Mozilla без перенаправлений: два доступных адреса подтверждают трафик, повторный успех только одного отмечается как частичная доступность.
- Добавлен общий каталог восьми списков GitHub, поддержка VMess в подписках, чередование источников и удаление повторов. При ошибке GitHub используется jsDelivr; загрузка ограничена 4 МиБ на источник.
- Списки автоматически обновляются каждые 15 минут при открытой вкладке внешних серверов и отключённом VPN. Результаты старше 15 минут отмечаются устаревшими. Ошибки загрузки, конфигурации и запуска ядра показываются отдельно от сетевых таймаутов.
- Исправлена передача gRPC serviceName и VMess WebSocket Host; Android дополнительно сохраняет параметры HTTPUpgrade.
- Служебные Android broadcast-события защищены разрешениями приложения; межпроцессные события VPN адресуются явно.
- Android backup исключает старые настройки VPN, чтобы приватные данные не попадали в резервные копии.
- Подключена сборка нативного VPN-моста для поддерживаемой приложением архитектуры ARM64.
- CI проверяет наличие Android signing secrets и существование GitHub Release перед загрузкой артефактов; файлы Windows и Android получают имена с версией.
- README и инструкции сборки приведены в соответствие с текущими требованиями и ограничениями безопасности.

## Артефакты

- `AnariseVPN-Windows-x64-v1.4.16.zip` — Windows x64, framework-dependent publish; требуются .NET 8 Desktop Runtime и WebView2 Runtime.
- `AnariseVPN-Android-debug-v1.4.16.apk` — ARM64 debug APK для тестирования; не production-подпись и не предназначен для обновления production-версии.
- `SHA256SUMS.txt` — контрольные суммы приложенных файлов.

Production APK будет собран CI отдельно после настройки GitHub Secrets с действующим Android keystore. Не заменяйте им debug APK до проверки подписи и установки.

## Проверки

- Windows Release build и publish: успешно; сборка выдаёт nullable-предупреждения.
- Windows parser smoke checks: 6/6; trusted-binary manifest и `StatisticsService`: успешно.
- Проверки обхода внешнего списка: 6/6; классификация HTTPS, конфигурации ядер и обработка источников: 10/10.
- Android `assembleDebug`: успешно; APK подписан debug-ключом, содержит ARM64 нативный мост и движки.
- Android SDK unit-тесты: 2/2 — проверка ответов и условий подтверждения трафика.
- Живая проверка Windows 30 конфигураций: 2 подтверждены через два HTTPS-адреса, 23 таймаута, 5 ошибок запуска ядра. Все восемь итоговых источников доступны на момент проверки. Это результат текущей сети, а не гарантия работы на другом устройстве или у другого провайдера.
- `git diff --check`: успешно.

HTTPS-проверка не измеряет пропускную способность, UDP-трафик или работу полного TUN-маршрута. Android VPN на физическом устройстве в этой сессии не проверялся.
