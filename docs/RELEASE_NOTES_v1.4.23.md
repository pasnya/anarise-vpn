# ANARISE VPN v1.4.23

## Новое

- Добавлен поиск обновлений и обновление приложения из интерфейса Windows, macOS и Android.
- Режимы TUN и «Системный прокси» перенесены на главный экран Windows и macOS; подсказки объясняют, какой трафик проходит через VPN в каждом режиме.
- На Android добавлена информация о доступном режиме TUN и о том, почему системный прокси в этой версии не поддерживается.
- Закреплена подпись Android production-релизов постоянным ключом проекта.

## Артефакты

- `AnariseVPN-Windows-x64-v1.4.23.zip`
- `AnariseVPN-macOS-arm64-v1.4.23.dmg` и `.zip`
- `AnariseVPN-macOS-x64-v1.4.23.dmg` и `.zip`
- `AnariseVPN-Android-arm64-v1.4.23.apk`

Android APK подписывается закреплённым production-сертификатом. Обновление поверх старой установки возможно, только если её сертификат совпадает с сертификатом релиза.
