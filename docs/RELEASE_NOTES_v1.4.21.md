### Что нового в v1.4.21:

1. **Принципиально новый Zen-дизайн интерфейса (Windows, macOS, Android)**:
   - Минималистичный и чистый интерфейс с максимумом свободного пространства («воздуха»).
   - Крупная круглая центральная кнопка включения/отключения VPN (⏻) с мягкой анимацией дыхания при установке соединения.
   - Понятный человечный статус защиты («Вы защищены», «Защита выключена») без перегруженных технических плашек на первом плане.
   - Удобная интерактивная карточка выбранного сервера под кнопкой для быстрого перехода к списку локаций в один клик.
   - Быстрые аккуратные кнопки для добавления ссылки из буфера и импорта подписок.
   - Единая цветовая палитра на всех платформах: благородный шалфейный изумруд (`#267A70`), чистые светлые поверхности и контрастная типографика.

2. **Исправления и совместимость macOS (Apple Silicon M1/M2/M3 & Intel)**:
   - В бандл `Info.plist` добавлен дескриптор платформ `CFBundleSupportedPlatforms: MacOSX` для корректной валидации LaunchServices на macOS Sequoia и Tahoe.
   - В скрипт сборщика `build-macos.sh` добавлена рекурсивная зачистка расширенных атрибутов (`xattr -cr`) на всем каталоге DMG-образа перед созданием архива.
   - Установлены полные исполняемые права `chmod -R a+rX` для всех динамических библиотек и бинарников внутри `.app`.
   - В корень DMG-образа добавлена наглядная памятка `КАК ОТКРЫТЬ ANARISE.txt` для обхода системного Gatekeeper macOS при первом запуске.
